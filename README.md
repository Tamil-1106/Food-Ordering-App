# TastyTrails

Small Java project. This repository was prepared locally by the assistant.

How to push to GitHub

1. Create a repo on GitHub (or use the GitHub CLI `gh repo create`).
2. Add the remote and push:

```powershell
git remote add origin <GIT_URL>
git branch -M main
git push -u origin main
```

Or, if you have the GitHub CLI installed and authenticated:

```powershell
gh repo create <repo-name> --public --source=. --remote=origin --push
```

If you want me to push now, provide the remote URL (or allow me to create the repo using `gh`).
